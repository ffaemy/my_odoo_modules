Odooistic Price Override Wizard (OWL)
=================================

Adds a **Price Override** button on Sale Orders (draft/sent).
Opens an **OWL Dialog** to apply a bulk discount % with a live totals preview.

- Preview uses server-side tax computation (compute_all) for accuracy.
- Apply writes the discount to all non-display order lines.

Next steps: add pricing modes, per-line tables, approvals, margin checks.
