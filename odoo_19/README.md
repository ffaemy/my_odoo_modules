- Odoo Version: **19.0**

## ⚠️ Important

These modules are provided primarily for learning and demonstration purposes.

Before using any module in a production environment:

- Review the source code
- Test it in a staging environment
- Check dependencies
- Verify compatibility with your Odoo installation
- Take a database backup
